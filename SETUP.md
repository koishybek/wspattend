# Поставь себе авто-отметку WSP (свой аккаунт, ~15 минут)

Эта инструкция — чтобы **каждый поднял бота себе сам**. Твой логин и пароль от WSP
остаются только в твоём GitHub, никто чужой их не видит. Тот, кто дал тебе эту ссылку,
к твоему аккаунту доступа не имеет.

> Это автоматизация **твоего** аккаунта под **твою** ответственность: отметка о посещении —
> это про честность перед вузом. Решаешь сам.

Нужно: аккаунт **GitHub** и аккаунт **Cloudflare** (оба бесплатные).

---

## Часть 1. Форк репозитория (2 минуты)

1. Открой репозиторий-шаблон: **https://github.com/koishybek/wspattend**
2. Справа вверху нажми **Fork** → **Create fork**. У тебя появится своя копия.

## Часть 2. Вписать свой логин и пароль (3 минуты)

В своей копии репозитория:
1. **Settings** (вкладка вверху) → слева **Secrets and variables** → **Actions**.
2. Кнопка **New repository secret**, добавь два секрета:
   - Имя `WSP_LOGIN`, значение — твой логин от WSP (поле «Қолданушы»).
   - Имя `WSP_PASSWORD`, значение — твой пароль.

Пароль хранится в зашифрованных секретах GitHub, в коде его нет.

## Часть 3. Вписать своё расписание (5 минут)

1. В репозитории открой файл **`server/schedule.json`** → карандаш (Edit).
2. Впиши свои пары блоками. Формат строки:
   ```json
   { "dow": 2, "start": "08:00", "end": "10:00", "name": "Любое название" }
   ```
   - `dow`: день недели. 1=Пн, 2=Вт, 3=Ср, 4=Чт, 5=Пт, 6=Сб, 0=Вс.
   - `start`/`end`: начало и конец блока пар по времени Алматы. Пары подряд объединяй в один блок.
3. Внизу **Commit changes**.

## Часть 4. Будильник на Cloudflare — чтобы запускалось вовремя (5 минут)

Без этого шага встроенный таймер GitHub часто опаздывает или вообще не срабатывает — проверено.
Будильник на Cloudflare запускает бота точно по времени.

1. Установи Node.js (если нет): https://nodejs.org → LTS.
2. Скачай свою копию репозитория на комп: кнопка **Code** → **Download ZIP**, распакуй.
3. Открой папку `alarm`, в файле `src/index.js` поправь список `STARTS_UTC` под своё расписание.
   Время там в **UTC = время Алматы − 5 часов**, и ставится на **начало блока минус 25 минут**.
   Пример: пара в 08:00 Алматы → 07:35 Алматы → в UTC это `02:35` → строка `[2, '02:35'],`.
4. В терминале в папке `alarm`:
   ```bash
   npx wrangler login              # откроется браузер, нажми Allow
   npx wrangler deploy
   ```
5. Создай токен GitHub, чтобы будильник мог запускать бота:
   - https://github.com/settings/personal-access-tokens/new
   - **Only select repositories** → выбери свой форк `wspattend`
   - **Repository permissions → Actions → Read and write** → Generate
6. Положи токен в будильник (в папке `alarm`):
   ```bash
   npx wrangler secret put GH_TOKEN
   ```
   вставь токен, Enter. И поправь `REPO` в `alarm/wrangler.jsonc` на `твой-логин/wspattend`,
   затем снова `npx wrangler deploy`.

Готово. Ноут можно выключать — всё работает в облаке.

## Telegram-уведомления (по желанию)

Чтобы бот писал «✅ отметился»:
1. В @BotFather создай бота, получи токен. Нажми **Start** своему боту.
2. У @userinfobot возьми свой numeric **Id**.
3. В GitHub → Settings → Secrets → Actions добавь:
   - `TELEGRAM_BOT_TOKEN` — токен бота,
   - `TELEGRAM_CHAT_ID` — свой Id.

## Проверка

GitHub → вкладка **Actions** → **WSP авто-отметка** → **Run workflow** → mode `dump`.
В логе должно быть `login: успех`. Если да — всё подключено верно.

## Если не работает

- `не смог залогиниться` → проверь `WSP_LOGIN` / `WSP_PASSWORD`.
- Бот не жмёт кнопку → в логе `dump` видно все кнопки; поправь `TARGET_STEMS` в workflow под нужный текст.
